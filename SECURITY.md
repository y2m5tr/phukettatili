# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please send an email to security@phukettatili.com (veya uygun bir e-posta adresi).

**Please do not create a public GitHub issue for security vulnerabilities.**

We will respond to your report within 48 hours and work with you to resolve the issue promptly.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Security Best Practices

This project follows these security practices:

- All dependencies are regularly updated
- Input validation on all user-facing forms
- Content Security Policy headers
- HTTPS-only in production
- No sensitive data in client-side code
- Regular security audits
